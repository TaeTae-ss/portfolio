## 🚀 Projects

### 🏃 Runmate

러닝 모임을 생성하고 다른 사용자와 함께 러닝에 참여할 수 있는 웹 서비스

**Tech Stack**

`Java` `Spring Boot` `Spring Data JPA` `Spring Security` `JWT` `Oracle` `React`

**주요 기능**

**👤 회원**

* 회원가입 / 로그인
* 회원가입 유효성 검사 및 중복 확인
* JWT 기반 인증 및 인가
* 회원정보 수정 / 탈퇴
* 마이페이지

**🏃 러닝 모임**

* 러닝 모임 CRUD
* 모집 상태에 따른 모집 여부 변경
* 좋아요 토글
* 지역 · 날짜 · 거리별 검색
* 최신순 · 오래된순 · 인기순 정렬

**🙋 참가**

* 러닝 모임 참가 / 취소
* 참여자 조회
* 중복 참가 불가

**💬 후기**

* 후기 작성 및 조회
* 모임 종료 여부에 따른 후기 작성 권한 처리
* 참여 회원 여부 확인을 통한 후기 작성 제한

**🛡️ 관리자**

* 관리자 전용 페이지
* 회원 관리
* 회원 권한 관리
* 권한에 따른 기능 제한
