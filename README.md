## 🚀 주요 기능

| 구분           | 기능                                                       |
| ------------ | -------------------------------------------------------- |
| 👤 **회원**    | 회원가입 / 로그인 · 유효성 검사 및 중복 확인 · 회원정보 수정 / 탈퇴 · 마이페이지       |
| 🏃 **러닝 모임** | 모임 CRUD · 모집 상태 변경 · 좋아요 · 지역/날짜/거리 검색 · 최신순/오래된순/인기순 정렬 |
| 🙋 **참가**    | 모임 참가 / 취소 · 참여자 조회 · 중복 참가 방지                           |
| 💬 **후기**    | 후기 작성 및 조회 · 종료된 모임의 참여 회원만 후기 작성 가능                     |
| 🛡️ **관리자**  | 관리자 페이지 · 회원 관리 · 회원 권한 관리 · 권한에 따른 기능 제한                |
