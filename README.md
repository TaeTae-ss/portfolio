## 🚀 Projects

### 🏃 Runmate

러닝 모임을 생성하고 다른 사용자와 함께 러닝에 참여할 수 있는 웹 서비스

**Tech Stack**

`Java` `Spring Boot` `Spring Data JPA` `Spring Security` `JWT` `Oracle` `React`

**주요 기능**

* 회원가입 / 로그인
* JWT 기반 인증 및 인가
* 러닝 모임 CRUD
* 러닝 모임 참가 / 취소
* 후기 작성 및 조회
* 참여자 조회
* 마이페이지
* 관리자 전용 페이지
* 권한에 따른 기능 제한

**담당 기능**

* 회원가입 / 로그인
* Spring Security 기반 인증 및 인가
* JWT 발급 및 검증
* 마이페이지
* 관리자 기능
* 회원 및 후기 관련 API 구현
* React 프론트엔드와 REST API 연동

**Troubleshooting**

* Spring Security 적용 후 발생한 `401 Unauthorized` 문제 해결
* JWT 인증 과정에서 발생한 `401 / 403` 문제 해결
* JWT 검증 후 `SecurityContext`에 인증 객체를 등록하여 인증 흐름 구현

👉 [Runmate Backend](https://github.com/TaeTae-ss/runmate-backend)
